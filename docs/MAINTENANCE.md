# 保守運用ガイド

## 監視
- フロントエラーを収集（Sentry互換）
- Lighthouse / Core Web Vitals を定期確認
- API / DB 使用量を週次レビュー

## バックアップ
- 現行方式: Google スプレッドシートを週次CSVエクスポート
- 移行後方式: Firestore定期エクスポート + Supabaseオブジェクトバックアップ

## スケーリング
- 一覧系はすべてページネーション
- いいね/コメント数は非正規化カウンタ
- 古いストーリーはアーカイブ領域へ移動

## 有料プラン移行時
- Firestore の read/write 枠拡張
- Supabase の容量・帯域拡張
- 画像変換/非同期処理の導入
